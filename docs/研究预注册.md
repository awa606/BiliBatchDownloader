## 固定实验顺序

### U01 账号与关注

- Hypothesis：旧工具的专用 Chrome 档案包含可用的 B站会话。
- Input：仅专用档案的 B站 Cookie，保存在内存，不记录内容，不访问其他浏览器档案。
- Procedure：读取会话 → 检查是否存在 SESSDATA → 单次请求 nav → 验证 code=0 且 isLogin=true → 再进行关注分页。
- Metrics：Cookie 是否可用、nav 业务码、是否登录、分页数、唯一UID数量、重复量、平台总量。
- Pass：实际登录成立；分页遍历完整且数量一致才判 complete。首次固定前两页；总量超过250时再核验第5/6页边界，边界正常后再决定完整性验证。
- Stop：Cookie 解密失败或缺少会话、登录失效、HTTP 412/429、业务码 -401/-352、验证页面、关键字段缺失，停止在线实验，不换账号/IP，不无限重试。

U01追加验证（2026-10-16，用户重新登录后）：本人登录已通过，固定第1/2/5/6页均正常，共200个不同UID；平台总量为386。下一次限定遍历第1至8页（每页50，含nav最多9请求、间隔至少1秒），要求唯一UID总数386、无重复、最后页36条。此追加由已通过边界测试触发，不覆盖第一次-101或第二次PARTIAL证据；遇限制仍立即停止。

### U02 视频

固定普通视频与多P视频各1条，先检查身份、CID、标签、描述、封面和格式，再做小样本下载、合并、取消/恢复与本地打开。媒体仅在实验目录中本地保存，不上传。

U02真实下载追加：以上元数据通过后，固定下载BV13x41117TL的P1以及BV1bK411W797的P1/P2，共3资产。选择不高于360p的AVC独立视频流及AAC音轨，缺失则停止，不改用其他样本或格式。实验使用原工具已存在的FFmpeg，仅执行、不复制分发；当前无同目录ffprobe，明确使用FFmpeg完整本地解码验证音轨/视频轨与时长，不能声称执行过ffprobe。最多36次请求（含nav），0重试；元数据禁止跳转，媒体仅已选择URL与B站CDN域，最多2次CDN跳转并计数。每响应媒体上限150MiB，worker时限230秒，关闭专属Windows Job后清理等待最多5秒；文件仅写入新建`.artifacts/video-download-*`目录，中断文件保留。通过要求3项文件实际存在、BV/CID一致、音视频轨均存在、时长偏差不超过2秒或2.5%、完整解码成功、输出大小和SHA-256可核验。首次失败即停；截图、人工播放、取消恢复另列未验证。

### U03 动态

固定多图、GIF/动图、动态关联视频、转发、纯文字各1条；Live Photo 和独立动态短视频若存在则追加各1条。来自上游测试的URL只是候选，必须核验当前类型。检查原作者/发布者、动态ID、媒体数量及顺序、格式和关联视频。缺样本不算通过。

U03单变量诊断追加（2026-10-16）：固定多图样本首次返回 gallery `HttpError`，原探针遗漏其 response 状态。离线源码检查已确认该异常有 `response` 字段。只增加状态码/响应SHA捕获，不改版本、Cookie来源、URL、请求headers、重试或跳转策略；同一图集仅追加1次诊断，命名独立 evidence。目标是确定失败层，不是获得成功样本；首次失败永久保留。若确认平台限制，本轮不再发起B站请求。

U03入口诊断追加：上述诊断明确为HTTP404，未确认412/429等访问限制。下一项Hypothesis：同一动态ID仍存在，但opus页面入口不再可读。固定同ID，使用当前yt-dlp引用的动态detail读取入口仅1次（外加1次nav），检查动态是否存在及类型/作者/图片数量。此项不是gallery通过证据；如详情也不可用则停止该样本，保留404和详情结果，不冒充解析成功。

U03用户样本追加（2026-10-16）：用户提供3条当前可打开链接，分别为独立动态视频1259442066581094421、实况图片1257912749013336118、纯图片1249456774436618276。先按纯图片→实况图片→独立动态视频顺序各执行1次detail诊断，每条最多nav+detail两请求。预期当前存在、作者/ID准确并能区分类型；数量与格式尚未知，不先填写成功预期。任一登录/平台限制立即停止全部在线实验；其他样本特有错误停止该样本，不换参数反复请求。新样本不替换上游404失败。实况图不等于GIF，独立动态视频也不假定存在BV或投稿列表项。诊断得到字段不等于媒体可下载。

U03图集候选追加：上述三个用户样本detail均code=0。纯图诊断看到4PNG；实况图诊断看到9JPG但未确认配套视频；动态视频给出BV1UdJ16cEqV。下一步对两条用户图片样本各进行一次gallery-dl元数据实验（每条nav+opus，最多2次请求、父进程45秒、无下载），检验其数量/顺序以及实况图配套视频是否被候选捕获。先纯图再实况图，若登录/平台限制立即停止；不据此消除旧样本404失败，也不把detail的静态图字段当作实况通过。
