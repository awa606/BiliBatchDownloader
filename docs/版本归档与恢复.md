## 恢复方法

1. 从上表对应Release取得精确资产，同时取得共享第三方源码材料；核对本页SHA-256。
2. 解压到新目录，再核对portable-manifest.json和原包SHA清单；保留应用源码与第三方声明。
3. 历史程序只使用临时空库或合成库，不能写入现用作品库。r8恢复后继续通过显式数据库目录的入口启动，公开包不携带私人库。
4. 后续清理继续逐项检查引用、占用、重解析路径、文件树和远端完整内容；不整删dist、build或.artifacts。
