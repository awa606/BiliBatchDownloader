# 图库元数据同响应对照与兼容修复

## 目标与边界

当前产品仍为0.2.0 VERIFY。0.3.0真实选组下载停在应用元数据转换，旧失败见[原始记录](图库联网字段结构失败-20261017.md)。本轮仅定位和修复字段兼容；在线只允许固定四图页一次登录加页面，共2请求，媒体0请求/0字节，不启动下载任务、FFmpeg或作品归档。旧包、库、媒体和失败证据保留。

## 研究问题与已有证据

- U01：上游原生提取能否处理应用拒绝的结构？两个合成场景已复现：`word:null`加有效`rich`被应用拒绝；同节点同时有`word`与`rich`时应用漏掉后者。上游均能读取。
- U02：实际固定页面具体在哪个字段失败？历史响应只保留SHA，不能离线重放。需要同一次响应的原生/应用对照，不能把合成NULL标题或两个已知问题当作实际原因。
- U03：上游不抛错是否代表正文完整？不是。其正文解析有捕获异常后跳过的分支，需要比较片段数量/摘要及结构，不能把空输出自动记为确认无内容。

## 成熟方案比较

| 方案 | 适合部分 | 限制与取舍 |
|---|---|---|
| 固定gallery-dl 1.32.16原生提取 | 已有本项目四图、实况下载证据；已有正文/标题/时间/话题字段 | GPL组件隔离边界保持；上游可能跳过异常正文，本地仍需段落与完整性检查；首选候选 |
| 官方metadata后处理器 | 对已有字段输出JSON、标签等 | 不补齐提取遗漏；不能替代已定义的字段状态；不新增原始元数据落盘 |
| gallery-dl-assistance | 图片、实况及文字归档流程参考 | 实际通过requests直接调用Web接口；没有证明更适合本项目，替换将引入第二套网络实现 |

官网Issue #9596和提交73a95bf修复过模块合并/空值问题；本地固定版本已包含该模式，不能重复套补丁宣布本次修复。v1.32.5已有正文等元数据支持；本轮不升级依赖或改用开发分支。

研究七问：已有方案是gallery-dl；可复用其固定提取入口及字段；最大风险是异常被上游忽略造成内容遗漏；最低成本验证是两个实现消费同一份内存数据；证据为合成原生入口测试、后续预注册一次在线报告；技术决策暂留空，待关键结构事实与修复验证；回退保留0.2与当前源码Git历史，不迁移旧库。整体Research仍NEEDS MORE EVIDENCE，本轮为既有模块局部兼容Bug修复，不扩展功能或重新设计接口。

## 最小验证与停止规则

复用现有原生HTTP保护、受限GZIP、Windows Job。Qt-free worker增加实验专用`--inspect-metadata`入口；产品`gallery_prepare/gallery_download`及数据库不变。只固定`1249456774436618276`和UID `1337856191`，原4PNG清单逐项核对。

两个解析器使用同一份已下载初始化数据的独立内存副本；应用拒绝后可以完成本地比较，但不得追加网络请求。上游Directory/Url消息只用于身份和清单核对，不创建DownloadJob或授权媒体地址。

约束：2请求、60秒worker、15秒网络等待、请求开始间隔至少1秒、零重试/跳转、页面原始与解码各3MiB。登录失败、风险页、HTTP异常、解码/身份/清单异常立即停止在线实验。不预取浏览器、不改入口/账户/代理、不扩大预算。字段拒绝不修改产品放行规则。

仅记录白名单字段名、类型、存在/真值、位置、计数和SHA；不保存正文、原始JSON、标签原文、未知字段名、地址或Cookie。结构报告最多4096字段。新响应与旧SHA相同时才用于解释旧失败；变化时只解释当前页面。

父脚本先登记代码/测试、依赖源码、冻结包、历史报告和原0.2库指纹，再以独占执行标记保证一次运行；超时终止Job，无法确定请求数时明确未知。执行后复核所有登记指纹。

## 最小修复与验收边界

时间字段采用固定上游`gallery_dl.dt.parse_ts`验证，仅接收整数或1～12位ASCII十进制整数字符串，归一为整数；拒绝负值、浮点/布尔、符号、空白、非数字、毫秒长度和越界，不猜日期格式或单位。上游本身会对解析失败返回空日期，因此必须检查解析结果，不把失败记为0。

正文改为分别处理已知word/rich，保留上游word→rich顺序；NULL分支只有在另一已知分支有效时才不阻塞。未知/空节点、异常标签对象、NULL标题等没有新增放行规则，段落和错误状态继续保留。用户接口、数据库、布局和媒体处理未变。

修复前对照和一次在线所用代码保存在提交257e2c4。修复后定向111 PASS/3工具环境SKIP；最终全量将显式设置FFmpeg，不把这3项跳过写作通过。源码/冻结回归及Windows CI结果完成后追加。真实页面修复后和原24请求选组链均NOT_RUN，不发布0.3、不清理包或证据。
