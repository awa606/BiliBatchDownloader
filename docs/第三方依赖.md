# 第三方依赖与分发边界

当前仅创建研究源码仓库，没有分发任何第三方可执行程序、新版应用包或下载媒体。自有 MIT 许可不覆盖第三方组件。

| 组件 | 固定版本 | 当前用途 | 分发前要求 |
|---|---|---|---|
| Python | 3.13.0 | 本地研究运行时 | 保留 PSF 与相关声明 |
| yt-dlp | 2026.8.19 | 本地会话读取、视频元数据实验 | 源码为 Unlicense；官方EXE含其他许可，不能直接推定同一许可 |
| gallery-dl | 1.32.16 | 图文候选实验，固定样本失败 | 固定安装版本声明 GPL-2.0-only；发布须核对完整许可与源码义务，隔离进程不自动免除分发责任 |
| pytest | 8.4.2 | 离线研究测试 | MIT |
| PySide6/QML | 候选6.11.1，本轮未安装 | 后续界面方案 | Research PASS后设计；核对实际Qt模块及第三方声明 |
| FFmpeg/FFprobe | 旧7.1用于现有视频预览；独立Gyan9.0.2 essentials用于图集验证及合成测试 | 两个9.0.2工具版本与发布方ZIP SHA已核验；真实图集未联网 | GPLv3构建，LICENSE/README保留本地；目前不分发二进制，未来发布仍需核对所有组件及对应源码 |

实际已安装研究依赖见 `requirements-research.lock.txt`。当前不复制 Douzy 桌面代码、素材、字体或标志；PixivDesk 的私有账号、作品及手册图片也不迁入公开仓库。

## 本轮工具核验

Gyan9.0.2 essentials ZIP的发布方SHA-256与本地下载一致：`60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba`，114,768,076字节。解压后FFmpeg/FFprobe均报告9.0.2；README声明GPLv3及源提交`946fcce07b`，LICENSE已保留。独立目录为`.artifacts/tools/gyan-9.0.2/`，`verification.json`保存ZIP、许可及两工具指纹；旧工具未覆盖，PATH未变。

来源：[FFmpeg官网列出的Windows构建](https://ffmpeg.org/download.html)、[Gyan固定9.0.2发布](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2)、[发布方SHA-256](https://www.gyan.dev/ffmpeg/builds/packages/ffmpeg-9.0.2-essentials_build.zip.sha256)。本轮仅本地执行/CI合成测试，不构成对新版应用分发依赖的最终选择。
