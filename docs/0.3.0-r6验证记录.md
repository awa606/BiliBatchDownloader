# 0.3.0 VERIFY r6：标题、标签及大部分展示文字可复制

## 用户反馈与修复

r5用户确认简介可复制，同时指出标题和标签也需要复制。r6扩展同一套文字控件，不改下载引擎、数据库结构或页面主体布局。

| 位置 | 操作 |
|---|---|
| 视频/图库详情的标题、作者、发布时间、标签和正文 | 鼠标拖选后Ctrl+C；焦点在字段内时Ctrl+A；右键复制所选或全文 |
| 图库选组页的作者、正文和标签 | 同上；原有勾选与下载按钮不变 |
| 作者列表、作品卡片、分P信息、路径、任务状态和提示 | 右键“复制文字”；复制完整字段，包括被省略号隐藏的部分 |
| 操作按钮、勾选框和筛选器 | 保留原操作，不把点击改成复制 |

列表继续使用Label的尺寸/省略能力，通过Qt QClipboard写入纯文本；详情继续使用Qt只读TextArea。所有复制仅由用户动作触发，不记录剪贴板内容，不访问B站。
