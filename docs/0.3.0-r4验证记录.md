# 0.3.0 VERIFY r4：正文复制、秒级时间及视频信息修复

## 用户反馈与原因

用户确认r3图库作品的时间、正文和标签正确；同时反馈视频时间不完整、BV1bK411W797正文/时间/标签缺失、正文不能选取复制。r3体验记为 **PARTIAL**，保留图库通过和视频缺陷的区别。

本机只读核对：BV13x41117TL已保存正整数发布时间、64字符简介和5标签，但视频详情使用仅日期格式；BV1bK411W797的正文长度0、时间0、标签pending。后者从旧脱敏下载报告登记文件，导入器未接入独立元数据结果。历史报告证明正文存在且有10标签，但没有保存正文原文或发布时间，不能据此编造补齐。

两个详情及选组页使用Label，不能选择；视频正文额外截断8行。修复采用Qt原生只读TextArea，保留纯文本与段落，支持鼠标选择、Ctrl+A/C和右键复制全文；超过显示高度可滚动，不裁掉数据。时间统一显示本机时区的年/月/日、时/分/秒；缺失时间仍明确待获取。
