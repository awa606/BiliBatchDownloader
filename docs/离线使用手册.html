BiliBatchDownloader 作者作品库

0.2.0 VERIFY 候选版。解压整个文件夹，双击 BiliBatchDownloader.exe。保留旁边的 BiliDeskWorker.exe 和 _internal 文件夹。

离线图库候选

0.2.0默认离线。本机已有资料请使用工程根目录“启动Bili图库候选版.cmd”；原r8入口保留。公开包为空库，直接启动使用独立的BiliBatchDownloaderGalleryVerify目录，不迁移r8库。

  1. 点击“图文／图片”作品，按原顺序选择缩略图或上一组/下一组。
  2. 实况默认显示照片；点“播放实况”播放一次，支持暂停、继续、重播及切回照片。切组或离开详情立即停止。配套视频无音轨属于预期。
  3. “打开原图”“默认播放器播放”“打开文件夹”先后台核对文件，再调用Windows关联程序；文件缺失或变化会明确提示。
  4. 设置中选“导入图片／实况报告”，选择已核验的本工具原生PASS报告，先预扫描核对作者UID、动态ID与数量，再确认登记。原文件不移动，重复导入不重复登记；文件变化/错配不部分提交。

未知标题、作者名、正文、发布时间和标签显示待获取；本版不联网补齐。实况JPG和MP4为同一组，MP4不另建视频作品。

浏览与播放

  1. 左侧选择本地作者，按分类浏览作品；支持标题、正文、作者、原标签搜索。
  2. 点击作品卡片，查看分P、原站信息和实际截图。缩略图是内容截图，不冒充原站封面。
  3. 点击“播放视频”交给系统默认播放器；“打开文件夹”打开原文件位置。本地检查独立于下载队列，文件不存在或大小变化会提示，不自动补写为完整。出现“已交给默认播放器”后，实际出画速度由播放器决定。

原视频模块添加与下载（本候选停用联网）

  1. 在旧工具的专用Chrome中登录B站，然后关闭该浏览器。
  2. 在“设置与导入”填写专用档案目录、选择新下载目录和本人安装的FFmpeg路径；FFprobe必须位于同目录。程序不分发外置FFmpeg工具，也不会自动联网安装工具；应用内播放使用Qt匹配的FFmpeg动态库。
  3. 点“添加视频”，粘贴BV号或视频链接，读取信息；然后在作品详情选择分P下载。
  4. 下载中心默认暂停视频派发，点“继续派发”开始；暂停不终止当前任务，取消会终止当前任务及子进程。失败或重启中断后可手动重新加入，零自动重试。

本版本每任务最多12次请求、230秒、最高360p和64MiB总HTTP传输量；元数据与响应头也计入该限额。限制触发后停止。不同视频、多P、新账号或平台状态不保证都通过；固定普通视频P1已完成原生下载和解码验证。

分类与数据

分类包含图文／图片、投稿视频、动态视频、待分类。没有可靠来源依据时保留待分类；详情页可以手工纠正。新文件按作者UID/分类/BV/CID存放；纠正分类不会移动已有文件。相同BV/CID不重复归档。

作品库保存在 %LOCALAPPDATA%\BiliBatchDownloaderGalleryVerify。关闭应用后可备份该目录。Cookie只在工作进程内存中读取，应用不保存Cookie文件。新包不含用户作品库、账号档案、媒体或测试截图。

本地报告导入

设置页可选择此前本工具生成的下载report.json和预览report.json。后台逐项核对SHA-256，原文件原位登记。仅支持已核验报告；通用目录预扫描导入尚未提供。研究样本路径是 bili_desktop\.artifacts\…，.artifacts是独立子目录。
