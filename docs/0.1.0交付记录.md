## 失败与修复保留

1. SQLite Spike初次未显式关闭连接，Windows临时清理失败；修复关闭连接后两个环境通过。
2. QML初次Windows路径加载及一处子对象后分号造成加载失败；改用本地QUrl并修复语法，保留诊断。
3. Job测试误将被终止进程的退出码0视为成功；改验终止耗时和没有成功结果消息，产品始终以结果消息为准。
4. r1打包钩子传入模块短名错误；改为完整 `PySide6.QtQml`。
5. r2/r3冻结启动失败：PATH污染收集了不兼容的ICU DLL；复用参考工程的隔离PATH构建，r4实际启动通过。新增启动失败本地报告，旧包保留。
6. 首轮缩放把系统150%和测试倍率叠加，实际225%/300%，不算约定缩放验收；离屏后备也出现字体目录告警。最终改用Windows本机实际DPR1/1.5/2重新验证，旧失败记录保留。

## 分发与数据边界

本机候选含GUI/worker、Qt运行时、手册、版本与SHA清单，不含媒体、数据库、Chrome档案或Cookie，也不捆绑FFmpeg、gallery-dl及PixivUtil2。用户设置指向本机独立FFmpeg工具对，公开包为空库。

源码与脱敏结论提交公开GitHub。Qt对应源码/第三方声明审查尚未完成，因此本轮不公开上传二进制Release；本机候选可供用户验收。未新增Release、不清理任何旧版本、环境、媒体或失败证据，释放空间为0。
